# Lovec — ліди без ріелтора, Братислава

Кожні 5 хв перевіряє Bazoš, Nehnuteľnosti, Reality.sk і TopReality, відкриває нові оголошення,
відсіює ріелторів і шле приватних продавців/орендодавців у Telegram. Статуси й нотатки — в дашборді
або кнопками прямо під повідомленням.

```
🟢 приватна     → пуш
🟡 можливо      → пуш з позначкою (ріелтори часто маскуються)
🔴 RK           → тихо в БД, вкладка «Відсіяні RK»
```

## Як відсіюються ріелтори

Скоринг у `lovec/classify.py`, кожне правило пише причину (видно в TG під спойлером і в дашборді):

- текст: «realitná kancelária», «provízia», «v zastúpení», «© text a fotografie», s.r.o., 3D-тур…
- приватні маркери: «predám / prenajmem», «od majiteľa», «náš byt», «sťahujeme sa»
- «RK nevolať / bez realitky» → **приватний**, але з позначкою 🤫 (дзвонити з цінністю, не з «продам вашу квартиру»)
- **телефон у 3+ оголошеннях = ріелтор** — найнадійніший сигнал, росте разом з базою
- Bazoš: скільки ще оголошень у цього продавця
- кнопка «🏢 Це ріелтор» кидає його телефон у чорний список — система вчиться на твоїх кліках

## Запуск локально (5 хв)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # впиши токен бота і пароль
python -m lovec check           # ← ПЕРШИМ ДІЛОМ
python -m lovec serve           # http://localhost:8000
```

### ⚠️ `check` обов'язковий перед деплоєм

Код написаний під реальну структуру Bazoš і Nehnuteľnosti, але **живцем зі своєї пісочниці я сайти не
ганяв** (там закритий інтернет). Reality.sk і TopReality — шаблони URL по пам'яті. `check` для кожного
пошуку покаже: скільки посилань знайшлось, що витяглось з 2 оголошень і як класифікувалось.
Якщо десь ❌ або ⚠️ — правиш регулярку `detail_re` / селектори в `lovec/sources/sites.py`
(або кидаєш вивід `check` в Claude Code — це 5-хвилинна правка).

Те саме, коли через пів року щось зламається: сайти міняють верстку — `check` покаже де.

## Telegram

1. @BotFather → `/newbot` → токен у `TELEGRAM_BOT_TOKEN`
2. Запусти Lovec, напиши боту `/start` — він відповість `chat_id`, впиши в `TELEGRAM_CHAT_ID`, перезапусти
3. `python -m lovec test-telegram`

Працюєш з партнером — додай бота в групу, візьми id групи (`-100…`). Команда `/stats` — зведення.

## Деплой на Hetzner (CX22, ~4 €/міс)

```bash
# на сервері (Ubuntu 24.04)
curl -fsSL https://get.docker.com | sh
git clone <твій-репо> lovec && cd lovec      # або scp -r
cp .env.example .env && nano .env
nano Caddyfile                                # свій домен, або ":80" якщо без домену
mkdir -p data
docker compose run --rm lovec python -m lovec check
docker compose up -d
docker compose logs -f lovec
```

Домен: A-запис `lovec.твійдомен.sk` → IP сервера, Caddy сам видасть HTTPS.
Змінив пошуки в `config.yaml` → `docker compose restart lovec`.
Бекап — це один файл `data/lovec.db`.

## Налаштування (`config.yaml`)

- **Свій пошук:** відкрий сайт, вистав фільтри (район, ціна, кімнати, *сортування від найновіших*),
  скопіюй URL у `searches`. Головне — найновіші зверху, бо читається лише перша сторінка.
- `interval_minutes: 5` — швидше не треба: швидкість реакції важлива, але бан IP гірший.
- `first_run_silent: true` — перший прохід лише запам'ятовує, що вже висить, щоб не прилетіло 300 пушів.
- Пороги `score` — якщо бачиш багато ріелторів у 🟡, зменш `suspicious_max` до 2.

## Чого тут свідомо немає

**Facebook Marketplace / групи.** Без логіну не читається, а скрейпінг з твого акаунта — пряме порушення
правил Meta і швидкий бан акаунта. Для FB краще ручний ритуал: збережені пошуки + сповіщення в групах
«Byty Bratislava bez RK», 10 хв на день.

практика. Автоматичні розсилки — ні.
